# PANELINHA — Letras do título

Nove PNGs RGBA individuais na ordem **P-A-N-E-L-I-N-H-A**, numerados de 01 a 09. As duas letras N e as duas letras A possuem arquivos próprios.

Use as imagens como elementos independentes para animar cada letra no menu inicial, mantendo a proporção e a identidade roxa, branca e dourada. Nenhuma arte deve ser achatada no fundo do menu. Consulte `MANIFESTO_LETRAS.json`.
